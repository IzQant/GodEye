## 1. 특징 공학 (ml/features.py)
전환쌍에 지오메트리/모멘텀 특징 추가:
- pos_x_norm, pos_y_norm : 좌표/맵크기 (0~1 정규화)
- dist_center_norm, angle_to_center : 맵 중앙과의 거리·방향 (가장자리→안쪽 당김 학습)
- prev_dx_n, prev_dy_n : 직전 이동(모멘텀) 정규화
- radius_norm : 반경/맵크기 (진행도)
과정: (1) cm 좌표를 맵크기로 정규화, (2) 중앙과의 관계를 명시 컬럼화,
      (3) 시퀀스(직전 이동)를 컬럼으로 펼쳐 트리 모델도 모멘텀 사용.

## 3. 결론
- 아무도 copy를 평균으로 못 이김 → 중심 무작위성의 벽 재확인.
- RF가 세 모델 중 최고. 일반 통념(부스팅>RF)과 반대인데, 데이터가 작아서(train 859행)
  부스팅이 과적합. → "대량 데이터면 부스팅 유리"가 아직 성립 안 함.
- 엔지니어링 특징은 RF엔 소폭 도움(168.8→165.7), 부스팅엔 해(과적합).
- 순서: 데이터 확충 → 그다음 부스팅 재도전. 지금은 RF(+약간 특징)가 최선.
