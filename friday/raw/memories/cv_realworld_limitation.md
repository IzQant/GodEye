# 실제 스크린샷 검출 한계 기록 (CV)

작성일: 2026-08-21 (Day 32 이후, 실제 에란겔 전체지도 phase1 테스트)

## 무슨 일이
실제 게임 전체지도 스크린샷(에란겔, phase1)으로 /api/analyze 이미지 경로를
테스트 → 자동 검출 실패(needs_manual=True).

## 원인 (실측)
- 흰 원 마스크에 잡힌 픽셀 5개뿐. 실제 안전지대 흰 원은 얇고 반투명한 회백색이라
  합성 기준의 "순백(V>180, S<40)" HSV 범위에 거의 안 걸림.
- 지도 배경이 바다·격자선 등 온통 파란 계열(파랑 후보 5.8만 px)이라 파란 마스크가
  물/격자 잡티를 주움 → 신뢰도 0.16의 오검출.
- phase 1은 다음 파란 원이 아직 표시되지 않음(첫 흰 원만). 빨간 원은 레드존(무관).

## 결론
- 색상 필터링(HSV)은 깨끗한 미니맵엔 되지만, 컬러풀한 실제 전체지도에선 불안정.
  → 예상된 한계. 그래서 '수동 입력 폴백' + 'phase는 사용자 입력' 설계를 미리 둠.
- 실제 스크린샷 예측의 신뢰 경로 = 사용자가 현재 원을 직접 표시(사람 눈엔 잘 보임).
- 자동 검출을 실제 지도에서 제대로 하려면 딥러닝 검출(YOLO 등, 로드맵 확장 Phase 6) 필요.
  현재 단계에선 과함.

## 조치
- 수동 입력을 '숫자 타이핑' → '이미지 클릭으로 중심 찍고 드래그로 반경' 방식으로 개선.
  (실제 스크린샷 + phase 입력만으로 예측이 실용적으로 되도록.)
- HSV 자동 검출은 유지하되 보조 수단으로 둔다.

## 향후(선택)
- 실 스크린샷 라벨 모아 흰 원 HSV 재튜닝 또는 HoughCircles 시도.
- 근본 개선은 딥러닝 검출(Phase 6).
