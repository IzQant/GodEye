# 확장 로드맵 (조정 확정판)

작성일: 2026-08-30 (6주 로드맵 종료 시점, 사용자 확정)
전제: 6주 로드맵(v1.0, 배포된 웹 서비스)이 완료된 상태에서 진행.

원래 로드맵의 Phase 5~7을, 이번 프로젝트에서 확인한 사실(검출이 실전 병목,
중심 점 예측은 무작위성 한계, 히트맵/분포가 실질 개선)에 맞춰 순서를 재정렬함.

## 확정 순서
1) 딥러닝 검출  →  2) 데이터 확충 + 맵별 모델  →  3) 시계열 정교화
(실시간 웹캠 연동은 위 3개 이후 선택 항목으로 보류)

---

## 1단계. 딥러닝 검출 (원래 Phase 6)
목표: 실제 스크린샷/전체지도에서 흰 원(현재)·파란 원(다음)을 안정적으로 자동 검출.
배경: 색상(HSV) 기반은 실제 지도(바다·격자·UI)에서 불안정 → 현재는 4클릭 수동 보정으로 우회.
      자동화하려면 딥러닝 검출이 필요(cv_realworld_limitation.md).
접근:
- 라벨링 데이터셋 구축: 실제 스크린샷 + (텔레메트리 오버레이로 만든 준실사 라벨 활용 가능).
  make_map_overlays.py 산출물이 라벨 자동 생성의 출발점.
- YOLO 계열(또는 세그멘테이션)로 원 검출 학습. 다양한 맵/해상도/UI 스케일 대응.
- 기존 색상+Contour 방식과 정확도 비교. 실패 시 수동 폴백은 유지.
산출물: 딥러닝 검출 모델 + 성능 비교 리포트. /api/detect 자동화 강화.
성공 기준: 실제 스크린샷에서 색상 방식 대비 검출 성공률·정확도 유의미 향상.

## 2단계. 데이터 확충 + 맵별 모델 (원래 Phase 7 일부)
목표: 후반 단계까지 신뢰할 데이터 확보 + 맵별 특화 모델로 정확도/보정 향상.
배경: 현재 ~162매치. 후반 단계 표본 부족, 맵별 통합 모델 상태.
필요량(분석 기준):
- 후반 단계까지 신뢰: 전체 500~800매치.
- 맵별 정밀화: 맵당 100~150매치 이상(주요 맵 5개면 750~1000+).
접근:
- collect_batch.py로 대량 수집(맵 필터링 로직 추가 고려).
- 맵별 하이브리드: 표본 충분한 맵은 전용 모델, 부족하면 전역 모델 폴백
  (model_service의 map_models 확장 자리 이미 마련됨).
- 데이터 충분해지면 LightGBM/XGBoost 재비교(현재는 소규모라 RF가 최선).
- 특징 추가: 육지/바다 마스크(해안 편향), 맵 내 위치, 모멘텀(features.py 확장).
산출물: 맵별 모델 세트 + 갱신된 히트맵. 성능/보정 리포트.
성공 기준: 후반 단계 coverage 안정화, 히트맵 영역 축소(sharpness↑).

## 3단계. 시계열 정교화 (원래 Phase 7 핵심)
목표: 단발 예측 → 이전 원들의 궤적을 활용한 다단계·분포 예측.
방향(중요): "중심 점 정확도"가 아니라 "분포/히트맵의 sharpness"를 높이는 것.
  (중심은 무작위성 한계 — model_reframe_transition.md.)
접근:
- LSTM/Transformer로 지금까지의 원 시퀀스 → 다음(및 다다음) 원 분포 예측.
- 출력을 점이 아니라 2D 분포/히트맵으로(혼합밀도 등). coverage/LL/영역면적으로 평가.
- 불확실성 시각화 고도화(신뢰구간·히트맵을 시간에 따라 갱신).
산출물: 시계열 기반 다단계 히트맵 예측 + 평가 리포트.
성공 기준: 같은 coverage에서 예측 영역 면적 감소(더 좁고 유용한 예측).

## 활용 가치 (기록)
사용자가 히트맵의 고확률 지역을 미리 선점하면, 자기장 축소 시 이동·노출을 줄이고
좋은 포지션을 선점하는 실질적 플레이 이점. 단, 확정이 아닌 확률이므로
"유력 지역 선점 + 퇴로 확보"로 사용. 중후반일수록 이점이 큼.
