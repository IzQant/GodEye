# 모델 재구성: 단계 전환 예측 (phase N → N+1)

작성일: 2026-08-21 (실제 phase1 예측이 "말이 안 됨" 이슈 대응)

## 문제
실제 스크린샷 phase1로 예측 시 결과가 무의미:
현재 r=216039 → 예측 r=215977 (거의 동일), ±64. "다음=현재"와 다를 바 없음.

## 원인
기존 학습 목표 = 같은 스냅샷의 safety(현재)→poison(다음경고).
초반 단계는 이 둘이 거의 동심원이라 목표 자체가 near-identity → 예측 무의미.

## 조치: 학습 목표 재구성
- ml/dataset_pairs.py: build_transition_pairs — 매치 내 phase N의 실제 원 →
  phase N+1의 실제 원 전환쌍 생성(인접 단계만).
- train_final.py / evaluate.py: 이 전환쌍으로 학습·평가.
- ZonePredictor 인터페이스·구조는 그대로(학습 데이터만 교체).

## 결과 (전환쌍 기준)
- 단계별 실제 이동: phase1 ~517m, 축소비 0.57 → 초반에 실제 변화가 큼.
- 재학습 후 phase1 예측 예시(현재 r=216039):
  r=123009(0.57배), 이동 141m, ±97883(≈980m). → 의미 있는 예측.
- 평가(다음 원 중심 오차, m): copy 159.1 / baseline 159.6 / RF 167.3 (평균).

## 정직한 발견
- RF/baseline이 copy(다음=현재)를 확실히 이기지 못함.
  PUBG 자기장 '중심'은 현재 원 안에서 상당히 무작위 → 중심 예측은 원리적 한계.
- 따라서 서비스 가치는 '중심 정확도'보다 '반경 축소 예측 + 불확실성 범위 제시'.
  결과 UI도 이 관점(예측 원 + 신뢰구간)으로 보여주는 게 정직함.
